# 可行制御力・トルク余裕の実装レビュー

対象は `fix/fc_min_calculation` の `75346ff2`。マージの第2親 `9b8bc022` を上流側の比較起点とし、`e42368bb` と、その計算を使用または置換する機体別実装を確認した。

全次元の射影領域について、符号付き支持平面余裕と推力区間の両端を使う今回の修正は妥当である。残る主な問題は、退化時の余裕の扱いと、力・トルクを同時に満たす推力が存在するかの判定である。

## 共通モデル

### 高：`stabilityCheck()` が釣合い未達の推力を通す

[`calcStaticThrust()`](../../../aerial_robot_model/src/model/base_model/robot_model.cpp#L487) は、推力制限を課さない擬似逆行列で推力を求める。[`stabilityCheck()`](../../../aerial_robot_model/src/model/base_model/robot_model.cpp#L495) は推力の値と射影余裕を確認するが、その推力で要求レンチを再現できるかは確認しない。

| 反例 | 射影余裕 | 擬似逆行列の推力 | 判定に必要な情報 |
| --- | --- | --- | --- |
| 4 kg、4基の推力軸が鉛直から同じ向きに30°傾く | 力・トルクともに 0 | 各 8.49281 N、範囲 2–30 N | `stabilityCheck()` は真。力残差は 19.6133 N |
| 互いに異なる4推力軸、推力範囲 0–1 N | 力 0.11450 N、トルク 0.04480 N·m | (0.81109, 0.89541, 0.84615, 0.58134) N | 拘束付き線形計画で共通配分は存在せず、擬似逆行列の残留トルクは約 0.06327 N·m |
| 鉛直4基、CoGからの x 偏差が (-1, 1, 2, 9) m、要求鉛直力 1 N | 力・トルクともに 0 | 最小成分 −0.05286 N | `stabilityCheck()` は偽。範囲 0–1 N 内の (0.5, 0.5, 0, 0) N で釣合い可能 |

最初の例ではロータ位置を `(±1, ±1, 0)` m とし、反トルクを零、判定しきい値を既定値の零とした。第2例は力・トルク射影が両方とも3次元で、要求は (0, 0, 2.5) N と零トルクである。第3例は現在の擬似逆行列配分を評価する場合には棄却でよいが、配分の存在判定としては偽陰性となる。

修正する場合、現在の配分を検証する判定では、対応する座標系と制御対象成分で力・トルクの残差を確認する。配分の存在を判定する場合は、同一の推力ベクトルに推力上下限と全ての制御対象成分の等式を課す。推力偏向を最適化する機体では、その自由度・範囲もモデルごとに扱う。残差と単位が異なる力・トルクの数値許容値も区別する。

### 高：退化時の零が「境界」と「判定不能」を兼ねる

[`calcFeasibleControlFDists()`](../../../aerial_robot_model/src/model/base_model/robot_model.cpp#L560) と [`calcFeasibleControlTDists()`](../../../aerial_robot_model/src/model/base_model/robot_model.cpp#L601) は、有効なペアがなければ零を返す。階数1以下では、要求が線分の外にあっても余裕は零になる。階数2でも、外積で得る法線は平面に垂直な方向だけなので、要求が同じ平面にある場合に平面内の境界からはみ出した分を検出できない。零は3次元の正の内接半径がないことを表せるが、符号付き可否の判定には不足する。

一律に零を棄却すると、鉛直推力だけを使う機体まで対象に含まれる。制御対象の次元を機体ごとに定め、その空間での余裕・要求の可否・計算の有効性を区別する。

### 中：平滑値のオーバーフローと余裕の過大評価

[`reluApprox()`](../../../aerial_robot_model/include/aerial_robot_model/utils/math_utils.h#L43) は `log(1 + exp(epsilon*x)) / epsilon` を直接計算する。有限の `x=20, epsilon=1000` で無限大になった。さらに `epsilon=10, x=-0.01` では、正確な ReLU が零のところで約 0.06444 になる。これは平滑化の性質で、境界付近で平滑な余裕を合否に流用すると、正確値より楽観的になる。

オーバーフローを避ける形で softplus を計算し、`epsilon` と推力境界の有限性・有効範囲を検査する。合否には正確値を使う。ペア単位では無効を `+inf` としているため、有限差分テストは [現行の NaN 置換](../../../aerial_robot_model/test/aerial_robot_model/numerical_jacobians.cpp#L391) に依存せず、同じ面が両評価で有効な場合と、平行対の出現・消滅を検査する場合を分ける。

### 中：推力下限を各ロータへ適用する前提と、追加質量

- [`staticsInit()`](../../../aerial_robot_model/src/model/base_model/robot_model.cpp#L120) は `rotor1` の限界を全ロータへ適用する。同一設定の機体には適合する。ロータによって上下限が異なる構成を対象とするなら、個別の限界を保持するか、均一性を読み込み時に確認する必要がある。
- [重心・質量の更新](../../../aerial_robot_model/src/model/base_model/robot_model.cpp#L343) は動的に登録した追加モジュールを加えるが、[`calcGravityWrenchOnRoot()`](../../../aerial_robot_model/src/model/base_model/robot_model.cpp#L426) は元の慣性マップだけを走査する。このAPIを使う構成では、力余裕と静止推力が異なる重量を基準にする。

## 機体別の経路

### HYDRUS と DRAGON の HydrusLike モード

[`calcFeasibleControlRollPitchDists()`](../../hydrus/src/hydrus_robot_model.cpp#L25) と[そのヤコビアン](../../hydrus/src/hydrus_robot_model.cpp#L52) は引き続き `[0, thrust_max]` を使う。例として平面トルク生成ベクトルを `(1,0), (0,1), (-3,-0.5)`、各推力を 1–2 N とすると、x成分は最大でも −1 N·m で零トルクは出せないが、現実装は余裕 +1 を返した。非対称な推力区間を使う場合は2次元の支持線の両側を調べる必要がある。また、平面射影が零の生成ベクトルは法線を定義せず、ヤコビアンのノルム除算から除外する必要がある。この余裕は [HYDRUS の安定性判定](../../hydrus/src/hydrus_robot_model.cpp#L174) で使用される。

### DRAGON の既定 FullVectoring モード

[既定の起動設定](../launch/bringup.launch#L9) では別の全方向推力モデルを使う。このモデルは[共通モデルの余裕更新を上書き](../include/dragon/model/full_vectoring_robot_model.h#L126)し、[水平力](../src/model/full_vectoring_robot_model.cpp#L757) と[トルク](../src/model/full_vectoring_robot_model.cpp#L804) をジンバル角の最適化用のスコアとして計算する。水平力は単位円や単位方向の加算、トルクは同一ロータ由来の直交推力成分を独立に加算する。そのため、スコアを推力の大きさ・ジンバル角制限・重量支持を同時に課した物理的な余裕として使用できない。

トルク側は平行対に `1e6` を置くため、全対が無効な場合にはその値が最小値として残る。有効対が存在しても、トルク生成が平面内に限られると最小値が零になり得る。これを[最適化の重みの分母](../src/model/full_vectoring_robot_model.cpp#L929)に使う前に、無効・零・非有限を処理する必要がある。既定DRAGON経路で今回のPRが物理的な余裕を修正したとみなすには、別途この経路を検証する必要がある。

## 確認方法と範囲

- 現行C++の共通余裕・安定性判定・平滑ヤコビアン・roll/pitch余裕の関数本体をEigenの独立ハーネスで実行した。上記の傾斜4軸、擬似逆行列による棄却、roll/pitchの誤判定、softplusのオーバーフローを確認した。
- 全次元の120ケースで推力箱の全頂点の凸包と符号付き支持平面余裕を比較した。最大絶対差は `1.42e-14`。正の射影余裕を持つ共通配分不能の例は、独立した線形計画で確認した。
- 推力 2–30 N の非退化の1条件で、平滑ヤコビアンを中心差分と比較した。最大成分差は力で `4.02e-9`、トルクで `6.15e-10`。
- 差分の空白検査は通過した。ROS統合テスト、Catkin再ビルド、実機・閉ループ飛行は未実施。
