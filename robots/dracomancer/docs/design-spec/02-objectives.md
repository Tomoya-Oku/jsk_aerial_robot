# 2. 研究目的

## 2.1 最終目的

本研究の目的は、

> **人間の上肢形態を多関節飛行ロボットの内部形状へ対応させ、操作者の意図した形状を飛行安定性・環境制約が許す範囲で最大限再現するテレオペレーションシステムを構築すること**

である。

検証対象は DRAGON とするが、理論上は、

- 多リンク構造
- 内部形状を表現する一般化座標
- ロボット形状の順運動学
- 飛行可能性または制約評価

が定義できる多関節飛行ロボットへ拡張可能な構成を目指す。

## 2.2 中心仮説

### H1: Morphology Interface
人間の腕の相対形状を入力とすることで、Joystick等で各ロボット関節を個別操作する場合より、複数内部関節を連続的・直感的に操作できる。

### H2: Mapping Representation
固定リンク対応による局所的形状写像と、腕全体を用いる全体形状写像では操作特性が異なり、特にロボット構造への一般化性と形状再現性に差が生じる。

### H3: Feasibility-aware Retargeting
人間の希望形状を飛行可能性制約の範囲内で補正することで、直接写像よりも推力飽和・危険形態を抑制しながら人間の形状意図を維持できる。

### H4: Environment-aware Retargeting
LiDARから得られる局所障害物情報を形態補正へ利用することで、人間の経路判断を維持したまま、狭隘部での衝突リスクを低減できる。

### H5: Haptic Feedback（拡張）
接触・安全制約を上肢へ力覚として返すことで、視覚のみの場合より接触状態・危険形態を把握しやすくできる。

## 2.3 研究範囲

### コア研究

1. Dracomancer Mk-II の装着型ハードウェア
2. 人間上肢形態の取得
3. 固定リンク対応写像
4. 全体形状写像
5. 両写像方式の比較
6. 飛行可能性を考慮した形態補正
7. LiDARを用いた局所衝突制約
8. Joystickと形状入力を分離した複合操作
9. DRAGONシミュレーション・実機による評価

### 第2優先

- 接触 wrench の力覚提示
- Safety haptic feedback
- Reference-link fixed operation

### 補助開発（研究の本筋外）

- Webブラウザから状態監視と遠隔操作を行うWebクライアント
- ROS bag等の実験ログをブラウザ上で再生し、共有URLで閲覧できる可視化・共有基盤

Webクライアントとログ共有基盤は、運用性・デモンストレーション性・実験結果の再現性を高めるためのプラスアルファ要素とし、形態写像やfeasibility-aware retargetingに関する研究上の新規性には含めない。

### 本研究で新規に作り込まないもの

- 新しい飛行ロボット機構
- 新しい飛行制御器
- SLAMそのもの
- 自律経路計画
- Semantic Mapping
- 新規 global trajectory planner
- DRAGON software 全体の全面的ROS 2移植

これらは既存実装を利用し、本研究の実装量を抑える。
