# Concept of Device
## Name: MANICA (Multi-modal Arm-type Nimble and Intuitive Control device for Articulated aerial robot)
## Requirements
- High-maneuverability
- High-controllability

## Methods
- Multi-modal (Haptic, EMG, etc.)
- Using human-arm

## Target robots
- Assuming DRAGON
- but also I wanna control other robots such as BEATLE

## Evaluation
- High-maneuverability
- Achieve tasks quicker than joystick-type controller
- High-controllability
- Usability for a person who uses for the first time
- Half-Automation 

## Teleoperation
- Movement of position and orientation of CoG
- Angles between links of articulated robots
- Control of an end-effector
